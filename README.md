The Glassmorphism To-Do List is a desktop productivity application that allows users to create, manage, complete, and delete tasks through a clean graphical user interface. The project demonstrates the use of Tkinter widgets, event handling, animations, and GUI design principles while providing a practical task management solution.

✨ Features
Add new tasks instantly.
Mark tasks as completed.
Delete unwanted tasks.
Animated multicolor title effect.
Hover effects on buttons.
Modern glassmorphism-inspired UI design.
User-friendly task management system.
Warning messages for invalid actions.
Responsive and organized layout.
🛠 Technologies Used
->Python 3.x
->Tkinter GUI Library
->Tkinter MessageBox
